# Interactive Web Calculator

A sleek, responsive, and modern web-based calculator application engineered using clean Semantic HTML5, advanced CSS3 architecture, and dynamic Vanilla JavaScript (ES6+). This project showcases precise DOM manipulation, robust math logic handling, and an intuitive user interface design with dynamic theme capabilities.

---

## Key Features

* **Real-Time Calculation Engine**: Seamlessly processes standard arithmetic operations (Addition, Subtraction, Multiplication, Division) instantly as the user inputs data.
* **Robust Logic Handling**: Built-in prevention for common edge-case bugs, such as multiple consecutive operators, decimal point duplication, and division-by-zero constraints.
* **Fully Responsive & Adaptive Layout**: Optimized using CSS Flexbox/Grid for cross-device compatibility, ensuring pixel-perfect rendering across mobile, tablet, and desktop viewports.
* **Modern Neomorphic / Minimalist UI**: Features smooth hover animations, tactile active click-states, and high-contrast typography to enhance digital accessibility.
* **Backspace & Clear Functions**: Equipped with immediate global clear (AC) and tactical backspace (DEL) triggers for optimized user control flows.
